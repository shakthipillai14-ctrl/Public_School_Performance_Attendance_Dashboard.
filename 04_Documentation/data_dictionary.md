# Data Dictionary

Column names below are taken from the supplied Excel workbook. Meaning is inferred from the column names and should be confirmed against the project requirements.

| Column | Description |
|---|---|

| `section` | Class section |

| `attendance_%` | Attendance percentage |
| `math_marks` | Mathematics marks |
| `english_marks` | English marks |
| `science_marks` | Science marks |
| `average_marks` | Average marks across subjects |
| `grade` | Grade assigned |
| `pass_fail` | Pass/fail result |
| `fee_status` | Fee payment status |
| `fee_due` | Fee amount due |
| `fee_paid` | Fee amount paid |
| `fee_balance` | Remaining fee balance |
